# 🔍 Algorithm Visualizer

An interactive web-based **Algorithm Visualizer** that helps students understand how algorithms work through step-by-step visual animations.

Instead of only reading code and theory, users can **see the algorithm in action**, making concepts easier to understand and remember.

## 🚀 Features

* 📊 Visualize sorting algorithms step-by-step
* 🔎 Visualize searching algorithms
* ⚡ Animated algorithm execution
* 🎚️ Adjustable animation/speed controls
* 🔄 Generate new/random input data
* 📱 Simple and responsive user interface
* 🧠 Helpful for understanding algorithm logic and time complexity

## 🧮 Algorithms Covered

### Sorting Algorithms

* Bubble Sort
* Selection Sort
* Insertion Sort
* Merge Sort
* Quick Sort

### Searching Algorithms

* Linear Search
* Binary Search

> More algorithms can be added in future updates.

## 🎯 How It Works

The visualizer represents data using visual elements such as bars.

For example, during **Bubble Sort**:

```text
Before:

| 8 | 3 | 6 | 2 | 5 |

       ↓ Compare

| 3 | 8 | 6 | 2 | 5 |

       ↓ Compare

| 3 | 6 | 8 | 2 | 5 |

       ↓ Continue...

After:

| 2 | 3 | 5 | 6 | 8 |
```

The visualization highlights the elements being compared, swapped, or processed so that the user can follow the algorithm step-by-step.

## ⏱️ Time Complexity

| Algorithm      |  Best Case | Average Case | Worst Case |
| -------------- | ---------: | -----------: | ---------: |
| Bubble Sort    |       O(n) |        O(n²) |      O(n²) |
| Selection Sort |      O(n²) |        O(n²) |      O(n²) |
| Insertion Sort |       O(n) |        O(n²) |      O(n²) |
| Merge Sort     | O(n log n) |   O(n log n) | O(n log n) |
| Quick Sort     | O(n log n) |   O(n log n) |      O(n²) |
| Linear Search  |       O(1) |         O(n) |       O(n) |
| Binary Search  |       O(1) |     O(log n) |   O(log n) |
